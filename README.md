<h1>
  Novelist - Говорящие Книги (Speaking Books)
</h1>
<blockquote>
  <p>
    Умное приложение для чтения и прослушивания книг, которое разрушает языковые барьеры. Благодаря интеграции с ИИ, приложение переводит любой загруженный текст на нужный язык и озвучивает его, создавая идеальную аудиокнигу под пользователя.
  </p>
</blockquote>

<h2>
  Основные возможности
</h2>
<ul>
  <li>
    <strong>
      AI-перевод и озвучка:
    </strong>
    Вы загружаете текст книги на сервер, где нейросеть обрабатывает его, переводит на выбранный язык и подготавливает к чтению. Приложение читает книгу вслух на любом языке, который захочет пользователь.
  </li>
  <li>
    <strong>
      Синхронизированный текст:
    </strong>
    Следите за текстом на экране — он отображается синхронно с тем, как приложение его озвучивает.
  </li>
  <li>
    <strong>
      Иллюстрации:
    </strong>
    Текст сопровождается картинками, что делает погружение в историю более глубоким и атмосферным.
  </li>
  <li>
    <strong>
      Умный тайминг:
    </strong>
    Приложение показывает точное время прослушивания — как общее время всей книги, так и длительность текущей главы. Вы всегда сможете спланировать свое время.
  </li>
  <li>
    <strong>
      Шеринг книг:
    </strong>
    Понравилась книга? В один клик сгенерируйте ссылку и поделитесь ею с друзьями.
  </li>
</ul>
<hr>
<h2>
  Как это работает
</h2>
<ol>
  <li>
    <strong>
      Загрузка:
    </strong>
    Исходный текст книги заливается на сервер приложения.
  </li>
  <li>
    <strong>
      AI-обработка:
    </strong>
    Серверная часть с помощью искусственного интеллекта переводит текст на нужный язык и подготавливает структуру (главы, тайминги).
  </li>
  <li>
    <strong>
      Пользовательский опыт:
    </strong>
    Пользователь открывает приложение, выбирает язык и начинает прослушивание. Приложение синхронно выводит текст на экран, показывает иллюстрации, таймеры и позволяет делиться ссылкой на книгу.
  </li>
</ol>
